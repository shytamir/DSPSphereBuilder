# DSP Sphere Builder

Plan a precise Dyson sphere a little at a time, without measuring angles or
laying out the whole design upfront. Each click adds a connected pentagon;
twelve clicks complete the framework. Construction already underway stays intact,
and the shells are yours to fill.

Fully supports Dyson Sphere Program **0.10.35.29057**; no mod update is needed
for this game update.

## Getting started

With at least 68° of Dyson sphere latitude unlocked, select one empty layer in
the sphere editor and use **Paint Next Patch**. Add another whenever you're ready,
without waiting for construction to finish. You can continue the same layer after
saving and loading. Editing the framework can prevent continuation.

## Installation

**Mod manager:** Install the package with its dependencies in your Dyson Sphere
Program profile, then launch the game with mods enabled.

**Manual:** With BepInEx 5.4.17 already installed, copy `DSPSphereBuilder.dll` from
the ZIP into `BepInEx/plugins/DSPSphereBuilder/` inside your game folder. Replace
the old copy when updating.
